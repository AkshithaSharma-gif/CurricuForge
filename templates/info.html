CurricuForge

AI-Powered Curriculum Generator

📌 What is CurricuForge?

CurricuForge is an AI-based web application designed to generate structured, semester-wise curricula for any technical or non-technical domain. It helps students, educators, and institutions plan learning paths efficiently based on user-defined inputs.

⚙️ How It Works

Users provide details such as domain, difficulty level, duration, and number of semesters. CurricuForge processes this input using AI models and instantly generates a detailed curriculum with subjects, topics, and learning outcomes.

✨ Key Features

  • AI-generated semester-wise curriculum
  • Customizable domains and skill levels
  • Instant generation with minimal input
  • Export curriculum as PDF
  • User-friendly and responsive interface

🛠 Technology Stack

  • Frontend: HTML, CSS, JavaScript
  • Backend: Python (Flask)
  • AI Integration: OpenAI / LLM APIs
  • Deployment: Local / Cloud-ready

🎯 Use Cases

  • Students planning structured learning paths
  • Educators designing course curricula
  • Institutions modernizing syllabus creation
  • Self-learners exploring new technologies
